# Contributing

Use Node.js 22 or newer. Run `npm ci`, `npm test`, `npm run check`, and
`npm run test:browser` before submitting a behavior change.

Keep changes focused, dependencies minimal, and examples generic. Tests must
cover the user-visible failure a change prevents. Never include a personal
browser profile, infrastructure config, credential, or network capture.

Commit subjects use `type: imperative subject` (72 characters maximum), with
`feat`, `fix`, `docs`, `test`, `chore`, `refactor`, or `ci`. No attribution trailers.
Use your configured Git identity; do not impersonate another author.
